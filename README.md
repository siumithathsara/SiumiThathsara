## 🚀 Featured Projects

### 🧠 [Serenity Mental Health Care System](https://github.com/siumithathsara/The-Serenity-Mental-Health-Therapy-Center-ORM-Hibernate.git)
*A high-performance enterprise-level solution for mental health resource management.*
- **Architecture:** Engineered using a **Strict Layered Architecture (DAO/BO patterns)** to ensure a clean separation of concerns, decoupling the presentation layer from the data access logic.
- **Data Persistence:** Utilized **Hibernate ORM** to manage complex database mappings, optimizing query performance and maintaining data integrity.
- **Business Logic:** Implemented comprehensive modules for patient records and therapy scheduling, ensuring high data visibility and role-based access control (RBAC) to handle sensitive healthcare data.
- **Tech Stack:** Java | JavaFX | Hibernate ORM | MySQL | Layered Architecture (DAO/BO)

- **UI/UX Design:** Crafted an intuitive interface using **JavaFX**, focusing on a clean user experience for front-desk operators.
